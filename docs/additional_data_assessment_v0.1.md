# `additional data` 可用性评估

日期：2026-11-08

## 结论

`additional data/` 具有较高的**资料整理价值**，但没有足以直接替换当前模型参数的新证据。当前建议：

- 不修改P001—P021的现有数值；
- 不修改R001—R019的现有规则；
- 不恢复E14区域分类；
- 不根据图像、试验或区域数据生成病害概率和产量损失；
- 将本次资料作为补充证据索引和后续取数清单。

## 采用判断

| 判断 | 内容 |
|---|---|
| 可直接采用 | 无核心参数可直接采用 |
| 可交叉确认 | E04来源论文 `10.1016/j.agwat.2021.107334` 与现有参数表一致 |
| 可作为背景 | 涝渍生理与产量文献、区域气象/遥感方法、病害图像方法 |
| 仅作探索数据 | `zenodo.23651962`、`gw6ynf7gvt`、谷胱甘肽处理数据 |
| 仅作未来图像模块 | 叶片图像、MLND、UAV元数据 |
| 暂不可用 | 未下载数据集、区域防洪情景、单地点弱证据PDF |

逐项判断见 `data/supplementary_source_assessment_v0.1.csv`。

## 对现有参数的影响

- E04：除交叉确认DOI外，没有新的生育期×淹水历时处理级产量表，因此不更新P013—P018。
- 渍水参数：没有普通夏玉米自然洪涝下5天、10天产量损失的新数据，因此不更新R001—R002。
- 环境参数：新增锈病PDF为单地点研究，不能覆盖现有规范性依据，因此不更新R006—R008。
- 施药窗口：没有新的早晚期随机试验和精确天数，不更新E02结论。
- E14：没有可用的区域遥感像元分类文件，继续保持不可用。
- 品种：关联群体和自交系数据不能外推到河南主导杂交种，继续只记录品种身份。

## 资料质量问题

- 27个数据集目录条目中，只有10个实际保存了文件，17个没有数据文件。
- 439个原始文件中包含417张图像，文件数量不能等同于独立田间样本量。
- `data_gap_analysis.md`中有一处写成343张叶片图，实际目录和数据集目录为417张。
- 图像测试卷存在少量文件标记与目录类别不一致，训练前必须清洗。
- “20块以下回归不稳定”只能作为项目内部采集建议，不是经过功效分析验证的统计阈值。
