# A—E 专项调研进入原型的方式（v0.3）

日期：2026-11-08

本版依据上级目录 A—E 专项调研、总览摘要和原始工作簿，对当前 Streamlit 单页做选择性整合。

## 1. 已进入原型的内容

### C：涝渍定量

- 将“田面明水天数”和“无明水但土壤饱和的渍水天数”拆开；
- 保留 V6、VT、R3 的生育期差异；
- 不把渍水折算成“相当于淹水几天”；
- 不计算“每延迟一天损失 X%”；
- 排水只使用“尽快排水”和3—4天共同临界带。

### D：病害环境参数

- 只对玉米南方锈病输出环境适宜度；
- 使用15—31℃可能范围、24—28℃最适范围、RH≥90%监测触发；
- 不把“适宜条件”写成“侵染阈值”；
- 不把5—6天潜育期加到洪涝日期上；
- 所有其他病害继续保持“仅监测/诊断”，不输出数值风险。

### E：四段决策窗口

页面现在明确展示：

1. 排水窗口；
2. 巡查窗口；
3. 诊断窗口；
4. 病害防治窗口。

系统强制“先诊断后用药”。未确认真菌性病害时，不进入药剂防治状态；积水、风速或高温不满足条件时，防治窗口直接锁定。

### A/B：病种范围与时间边界

- 南方锈病是当前唯一可参数化的病种；
- 茎基腐病只做监测、取样和诊断；
- 小斑/弯孢叶斑类只做监测；
- 穗腐病只做后期巡查与收获管理；
- 不建立“洪涝后第 N 天风险曲线”；
- 巡查建议写成“排水后3/7/14天、常规每7天、台风后每3天”，并标为规程或H级项目流程。

## 2. 新增规则文件

`data/decision_rules_v0.3.csv` 保存以下可追溯规则：

- 渍水5天和10天的有界损失先验；
- V6、VT表面淹水锚点；
- 3—4天排水临界带；
- 南方锈病温度、湿度和潜育期；
- 巡查、复查及安全作业条件；
- 诊断前置和禁止自动处方。

## 3. 暂不进入原型的内容

- 30天时滞风险滑块或曲线；
- 穗腐、顶腐、纹枯、大斑、根腐的风险分；
- 亩成本、投入产出比和理赔金额；
- 自动农药处方、剂量或具体产品推荐；
- 由区域灾害比例推算田块损失。

## 4. 仍存在的关键冲突

A—E 总览中写了 E02“台风后2天和21天”，但此前可访问的公开摘要只确认“早期/晚期”以及对应防效和增产率，未确认这两个精确天数。

因此当前原型继续：

- 使用“早期/晚期效应差”；
- 不显示“第2天/第21天必须施药”；
- 精确天数保留为 `unknown`，待全文或作者确认。

E20的严重度—产量斜率仍不进入模型；其产量表为聚合均值且缺少处理键，不能支持可靠斜率。

## 5. 当前定位

该版本是“涝渍暴露—病害监测—诊断—防治—作业安全”的证据约束决策原型，不是经过本地田块数据验证的病害预测模型。

页面把结果拆成五个不同维度：

- 数据完整性；
- 涝渍暴露事实；
- 南方锈病环境适宜度；
- 田间症状与诊断证据状态；
- 综合处置优先级。

综合处置优先级只表示排水、巡查和诊断的管理先后，不是病害发生概率。少于5天的渍水明确标为“存在胁迫但未达到定量锚点”，不再标为低风险；洪涝前田块基线未知时，页面同时列出当前可判断和不能判断的内容。

田间症状和专业诊断是两个独立输入。“尚未发现症状”不等于未感染，“尚未诊断”也不等于确诊；一旦专业诊断排除真菌性病害，系统关闭真菌环境评价和全部杀菌剂防治路径。

品种选择只记录身份。郑单958仅显示“有公开耐涝对比”的限定提示；其他品种和未知品种都不做无证据的耐涝或抗病风险加分。

E04的P013—P018只用于生育期×淹水历时的粗略关注分级。E14的P019—P021描述区域遥感像元，不能由田块明水天数替代；当前没有独立的区域像元输入，因此页面显示“暂无独立遥感像元数据”，E14参数不进入本次执行路径。

输入区明确标记预设为“情景假设值，非田间实测”；选择“自定义”不会回退到 V6 预设。数字输入允许缺失，未填写值不按0处理。温度或湿度缺失时，环境适宜度显示“数据不足，无法判断”；核心涝渍暴露缺失时，处置优先级显示“数据不足”，其他仍可判断的维度继续输出。

参数表由运行时读取记录生成，并区分“状态判断参数”和“解释性证据”。P013的4天 `time_value`服务于状态文字分支，25% `value_high`仅作解释性减产上界，不进入风险分数。

## 6. 缺口数据可得性更新

新增 `data/gap_availability_v0.1.csv`，把五项缺口分为“可查、只能部分查、查不到”：

- LWD仍无现成河南公开数据，页面只使用RH≥90%作为高湿提示；
- 田块退水日仍缺，现有证据只能到区域、村镇或地块群；
- 洪涝前病情基线只有区域/县级通报，页面允许用户选择田块已知状态，未知时保留`unknown`；
- 2026年河南12个主导品种中，仅郑单958有较明确公开耐涝对比，页面只做文字提示，不自动调整风险；
- 施药有约9.80—18.66元/亩等可核查参考价，排涝仍无公开亩均成本，当前不进入经济模型；
- “先涝后渍”试验已确认存在，但具体数值未取得，页面仍坚持将明水和渍水分开输入。
