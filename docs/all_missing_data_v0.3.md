# 项目全部缺失数据清单 v0.3

日期：2026-11-13

机器可读清单：

```text
data/all_missing_data_v0.3.csv
```

## 解释

本清单列的是“当前项目本地仍不完整或质量不足”的数据，不表示世界上完全没有类似数据。`public_substitute`列说明能否用公开数据部分替代。

## 田块身份和设计

- 精确田块边界；
- 受淹—未受淹配对编号；
- 处理组和对照角色；
- 土壤质地、排水条件、地形和洼地位置；
- 前茬、耕作、播种日期、品种和逐次生育期。

## 洪涝暴露

- 明水开始和结束时间；
- 实际退水和排水完成时间；
- 最大水深及逐日水深；
- 明水和土壤饱和分开记录；
- 积水面积比例、水温和浑浊度。

## 病害

- 洪涝前病情基线；
- 统一病害代码和疑似病原；
- 首次症状日期；
- 每次调查的病株率、病叶率和病情指数；
- 受害组织；
- 诊断方法、诊断结果和送检日期；
- 退水后3、7、14天连续调查；
- 症状照片、样方GPS、样本编号、周边菌源和洪前用药。

## 环境和干预

- 目标田块逐小时气温、冠层湿度、真实LWD、降雨、风速和土壤水分；
- 实际排水方式与时间；
- 农药产品、有效成分、剂量、日期和方式；
- 追肥、中耕、扶正等恢复措施；
- 排水和施药实际成本单据。

## 产量和质量

- 样方或田块实收产量和含水量；
- 配对对照田产量；
- 穗数、穗粒数、千粒重、空秆率和倒伏率；
- 籽粒品质和真菌毒素。

## 数据治理和遥感

- 观测人、时刻、原始记录编号；
- 每个字段的数据来源和证据等级；
- 缺失原因和照片存档；
- 数据共享许可和坐标脱敏规则；
- 可叠加SAR的田块边界；
- 事件时段像元级洪水掩膜；
- 作物类型和生育期；
- 遥感处理参数、重访和误差记录。

## 优先级

P0包括田块边界、配对设计、洪涝起止、水深、明水/饱和区分、洪前病情、连续病情、确诊结果、逐次生育期、实际干预和配对产量。缺少这些字段时，系统只能做情景筛查和监测，不能验证“洪涝后病害时滞”模型。

P1是气象、LWD、土壤水分、品种和管理背景，决定模型解释能力。P2是成本和品质等落地指标。
