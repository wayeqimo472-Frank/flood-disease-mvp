# 双轨验证方案与本地模拟渍水试验规程（v0.1）

**更新日期**：2026-11-28  
**适用范围**：本科大创一年期可独立落地的验证闭环（已显性剔除“联系县植保站/合作社索取原始台账”路径，避免不可控外部依赖卡死结题）。

---

## 一、为什么从三轨收束为“双轨验证”

在无长期驻点或县级农技站合作协议的条件下，依赖外部部门提供带“洪前基线＋涝后连续病情＋配对实测产量”的田块原始台账存在较大不确定性。因此本项目在立项申报与一年期执行中采用**双轨验证**：

1. **第一轨（已完成主体计算，持续补充回放案例）：公开多源实证 + 历史洪涝遥感气象回放**  
   在学校本地计算机即可完整复现与检验，不依赖当年天气是否发生极端暴雨。
2. **第二轨（立项后团队线下执行）：上海本地小规模可控模拟渍水试验**  
   依托校园盆栽或上海本地合作基地小块玉米试验区，低成本验证田块级数据采集链路、微气象记录仪接入与系统批量评估闭环。

## 三、第二轨：本地小规模模拟渍水试验规程（SOP）

### 1. 试验设计（最小可执行规模）
- **地点**：上海本地校内试验点或合作种植基地（玉米夏播或春播，推荐盆栽/微区 12–16 个独立单元）。
- **处理分组（4 组 × 3 重复 = 12 个观测单元）**：
  - `CK`：正常管理对照（无明水、不饱和渍水，土壤水分保持适宜）；
  - `W3`：V6 拔节期或 VT 抽雄期连续渍水/浅淹 **3 天**后立即排水；
  - `W5`：同生育期连续渍水/浅淹 **5 天**后排水；
  - `W7`：同生育期连续渍水/浅淹 **7 天**后排水。
- **配套低成本设备**：便携式温湿度记录仪（记录逐小时温度与 RH）、普通直尺（测明水深度 cm）、手机（按 `field_id_YYYYMMDD_part.jpg` 命名留痕）。

### 2. 观测时间线与字段要求
- **处理前基线（T-1d）**：记录品种、播期、生育期、株高/叶龄及基线异常情况（`pre_flood_baseline`）。
- **胁迫期（T0 至排水日）**：每日记录 `flood_days`、`waterlog_days`、`water_depth_cm`、`standing_water` 及实际排水时间（用于计算 `drainage_delay_hours`）。
- **排水后追踪（+3d、+7d、+14d）**：按系统四段巡查窗口对每个单元独立记录症状状态（`symptom_status`）、拍照编号（`photo_ref`）与恢复状况；若出现病斑仅记录疑似或送检确认，不虚构确诊标签。
- **收获测产（如条件允许）**：记录单株/小区产量及空秆倒伏情况；未到收获期则明确保留空白。

### 3. 数据入库与边界声明
- 组员统一使用专用模板 `data/local_trial_observation_template_v0.1.csv` 填写，缺项留空，不填 0 或估计值。
- 该试验用于**验证田块数据模板、微气象入库、批量状态机推演和排水窗口响应**；上海本地小气候及人工盆栽/微区试验结果**不直接外推为河南大田南方锈病发病概率参数**。
