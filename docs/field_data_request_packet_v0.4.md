# 田块观测数据请求单（v0.4）

本项目当前需要的是**田块级观测记录**，不是区域受灾面积或新闻中的村级概况。

## 最优先获得

1. 受淹田与未受淹对照田的配对关系；
2. 每块田的唯一编号、村、品种、播种日期和洪涝时生育期；
3. 明水开始日、实际退水日、最大水深、排水开始和完成时间；
4. 洪涝前一次病情调查；退水后3、7、14天至少三次病情记录；
5. 症状是否取样、诊断方法和确诊/排除结果；
6. 温度、湿度及数据来源；
7. 是否采取排水、追肥或施药措施，以及施药后7—10天复查结果；
8. 实收亩产或明确的“尚未测产”状态。

## 最低字段

可直接使用：

- `data/field_observation_template_v0.4.csv`；
- 页面“下载空白CSV模板”按钮。

`field_id`必填。无法获得的字段留空，不填写0、不填写“正常”或猜测值。

## 数据来源必须标注

- 农户回忆；
- 现场实测；
- 水位痕迹或插尺；
- 县级气象站；
- 田块传感器；
- 遥感推算；
- 区域业务通报；
- 实验室或植保部门诊断。

## 不能替代的字段

- 不能用区域洪水结束日替代田块退水日；
- 不能用县级病情通报替代涝前田块基线；
- 不能用相对湿度替代LWD；
- 不能用区域遥感像元分类替代田块明水天数；
- 不能用试验减产率替代具体田块实收产量。

## 发送给合作方的简短说明

> 我们正在验证一个“洪涝后作物脆弱性与病害风险筛查”原型。当前最需要的是同一区域受淹田与未受淹对照田的连续记录，重点是明水起止、实际退水时间、涝前病情基线、退水后3/7/14天症状与诊断，以及温湿度和数据来源。缺失数据请直接留空，不需要估算。所有记录仅用于科研原型校验，并会标注实测、遥感推算或区域背景来源。
