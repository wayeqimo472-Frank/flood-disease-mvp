# 公开数据扩展与缺口矩阵 v0.2

日期：2026-11-13

## 本轮新增

### One Acre Fund 小农玉米田调查

- DOI：`10.5281/zenodo.11122388`
- 许可：CC BY 4.0
- 14,773块田，覆盖7个国家；
- 实测产量、经纬度、品种和管理；
- 二元“水分过量影响”和“病害影响”；
- 杂交种病害耐受属性、CHIRP季节降水和土壤背景。

其中水分过量1,172块，病害影响381块，同时记录二者43块。两类均未记录的田块平均产量为2,977.2 kg/ha；两类同时记录的43块田平均产量为2,053.5 kg/ha。

这只是描述性关联。`water_excess`和`disease`都是农户报告的二元结果，不是暴露天数或病情指数，不能计算因果效应。

### 自然受淹玉米无人机试验

- DOI：`10.5281/zenodo.14261170`
- 许可：CC0
- 2020和2021年自然受淹田与对照田；
- 2020年1,594个小区；
- 定苗数、根倒、茎倒、籽粒重量、含水量；
- 多日期UAV指数和品种系谱。

214个小区备注含`standing water`。元数据没有统一给出哪个字段代表受淹或对照，因此不能仅凭字段名生成处理组。

### 真实叶面湿润时间

DIVINE西班牙站点：

- DOI：`10.5281/zenodo.11432589`
- 许可：CC BY 4.0
- 8,784条小时记录；
- 两节点叶面湿润分钟，以及温湿风、降雨和土壤水分。

意大利7站点：

- DOI：`10.17632/sd4b8vpvyb.1`
- 许可：CC BY-NC 4.0
- 55,550条小时记录；
- 叶片上表面、下表面湿润度和配套微气象。

这两组数据可以验证RH代理与真实LWD的差异，但没有匹配的玉米病害结果。

## RH≥90%代理检验

将“RH≥90%”作为叶面湿润代理，并与真实湿润小时比较：

| 数据 | 平均敏感度 | 平均特异度 | 平均精确率 |
|---|---:|---:|---:|
| DIVINE西班牙 | 0.417 | 0.991 | 0.828 |
| 意大利7站点 | 0.347 | 0.988 | 0.931 |

RH≥90%的误报较少，但漏报严重：DIVINE只能识别约42%的真实湿润小时，意大利平均只能识别约35%。因此RH代理可以用于保守提示，不能当作真实LWD，也不能用来宣称精确侵染时间。

## 已填补的缺口

| 缺口 | 当前状态 |
|---|---|
| 全球尺度的田块产量和管理 | 已有较充足公开数据 |
| 小农田块水分过量与病害的二元关联 | 已有观察性数据 |
| 自然受淹田的冠层和产量表型 | 有真实试验数据 |
| 真实叶面湿润时间 | 有西班牙和意大利小时数据 |
| 区域气象和遥感背景 | 有NASA POWER、Sentinel等开放服务 |
| 多种玉米病害严重度和产量 | 有US-CSCAP、CIMMYT等候选数据 |

## 仍未解决的核心缺口

1. 同一田块同时具备明水起止、最大水深、洪前病情、涝后连续病情、确诊结果和实收产量。
2. 严格的受淹—未受淹配对关系。
3. 田块级叶面湿润时间和田块级病害结果。
4. 干预日期、剂量、作业成本和干预后复查。
5. 除少数地区外，公开数据不能提供真实田块边界。

## 结论

公开数据已经可以把“气象背景、产量关系、病害图像、区域洪涝、叶面湿润和观测性水分过量—病害关系”做扎实。它们仍不能替代同田块连续观测，也不能让系统对具体田块输出经过验证的病害概率。

下一步应当停止无目标地继续增加图片数据集，转而优先申请三类数据：

- 农机或合作社的排水与作业记录；
- 植保站历史病情调查表；
- 保险机构的测产和损失记录。

详细登记见 `data/public_dataset_register_v0.2.csv` 和 `data/public_data_gap_matrix_v0.2.csv`。

全部50个缺失字段见 `data/all_missing_data_v0.3.csv`：其中P0为20项，P1为24项，P2为6项。
