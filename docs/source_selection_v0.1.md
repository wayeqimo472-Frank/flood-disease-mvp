# 模型参数来源取舍说明（v0.1）

日期：2026-11-08

配套文件：`data/model_parameter_priors_v0.1.csv`

## 1. 本轮采用原则

一条来源只有在能够提供以下至少一类信息时才进入参数表：

- 排水或追肥的时点效应；
- 淹水历时与产量损失；
- 病害防治的早晚期效应；
- 病害严重度与产量的关系。

仅有背景描述、无法取得数值、仅有摘要性结论、作物或病害不匹配的来源，不进入参数表。

本轮最终采用 4 条外部来源，形成 19 条参数记录：

| 来源 | 采用内容 | 参数 ID |
|---|---|---|
| E01 | 河南漯河夏玉米孕穗期排水延迟和追氮的产量效应 | P001—P004 |
| E02 | 台风后早期和晚期施药对南方锈病的防效与增产效应 | P005—P012 |
| E04 | 不同生育期、不同淹水历时下的产量损失锚点 | P013—P018 |
| E20 | 玉米锈病严重度与产量的原始小区数据关系 | P019 |

## 2. 关键边界

### E01

公开摘要是本次数值核对依据，已确认：

- 立即排水比延迟 3 天排水平均增产 21.28%；
- 立即排水后追氮比仅立即排水增产 8.07%；
- 延迟 3 天排水后追氮比仅延迟排水增产 15.33%；
- 延迟排水并追氮仍比立即排水低 5.04%。

这些是产量效应，不是病害防效，也不能单独证明排水降低南方锈病风险。

### E02

公开摘要已确认早施药的防效和增产率高于晚施药，但当前可访问摘要没有给出“台风后 2 天”和“台风后 21 天”的原文依据。

因此：

- 可以进入模型的是“早期与晚期”的效应差异；
- 不得在界面或报告中默认显示 48 小时、2 天或 21 天的精确窗口；
- 必须取得全文或作者确认后，才能补充精确时间参数。

### E04

采用中国农业科学院农田灌溉研究所公开新闻中明确列出的数值锚点。它能把淹水历时风险按 V3、V6、VT、R3 分开，但原始论文的完整曲线和交互效应尚未提取。

参数表保留“小于 25%”“接近 50%”“超过 20%”的原始语义，不把它们伪造成精确平均值。

### E20

本地工作簿的 MD5 与 Zenodo 官方文件一致，许可为 CC-BY-4.0。

- `severity` 工作表有 543 条数据记录；
- `severity, resources, RII` 有 336 条；
- `severity, RII, leaf nutrients` 有 72 条；
- `yield and harvest index` 有 36 条。

该研究是玉米锈病的间作、水分和养分试验，不是洪涝试验，也未确认为南方锈病。

在 36 条产量记录上计算的未调整线性斜率为 `-0.298687 t/ha/严重度单位`，但年度斜率从 `-0.321671` 到 `-0.049089`，说明关系并不稳定。参数表同时保留这个范围，禁止把合并斜率当作洪涝或南方锈病的因果效应。

## 4. 后续补证顺序

1. 优先取得 E02 全文，确认早晚期施药的具体天数和试验日期。
2. 尝试取得 E12 全文，补充可验证的成本参数。
3. 若 E11 可得全文，提取河南防控效果作为外部验证基准。
4. 等本项目拿到受灾田与对照田数据后，优先替换外部先验，而不是继续增加跨地区参数。

## 5. 使用限制

- 本表是模型参数先验，不是项目实测观测。
- 不同作物、病害、年份和试验设计不得直接合并。
- 文献预训练模型未经本项目数据校准，不能宣传为已验证预测模型。
- 成本缺失时显示 `unknown`，不得用其他地区或年份的成本自动填充。
