## 4. 冻结边界

v0.3是证据约束的情景筛查原型，不是经过本地田块数据验证的病害预测模型。

- 不输出病害发生概率；
- 不输出精确产量损失；
- 不自动提供农药名称、剂量或处方；
- E02精确施药天数仍未知；
- E14缺少独立区域遥感像元数据，当前不参与田块计算；
- LWD、田块退水日期和洪涝前田块病情基线仍缺；
- 未受淹对照田和多次田间观测仍缺。

## 5. 后续版本

v0.4只增加最小田块记录和CSV导入、校验、导出流程，不新增病害预测模型或外部API。任何缺失字段继续保留为未知。
