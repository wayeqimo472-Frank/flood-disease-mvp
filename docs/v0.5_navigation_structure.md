# v0.5 多页面结构

日期：2026-11-08

## 页面

| 页面 | 地址 | 职责 |
|---|---|---|
| 项目总览 | `/` | 展示当前情景摘要、数据完整性和功能入口 |
| 风险情景筛查 | `/risk` | 录入情景，计算并保存当前评估结果 |
| 干预窗口分析 | `/intervention` | 读取同一份已提交结果，展示四段窗口和判断边界 |
| 田块数据管理 | `/field-data` | 模板、上传、校验、批量结果和导出 |
| 参数与科研依据 | `/evidence` | 判断依据、实际参数调用、规则、限制和缺口 |

## 状态关系

- 风险页计算后，将 `current_inputs`、`current_result`、情景来源和修改字段保存到 Streamlit会话状态；
- 干预页和科研依据页只读取该状态，不重新生成另一套默认情景；
- 切换页面后返回风险页，会优先恢复最近一次已提交输入；
- 项目总览不会自动创建评估；当前会话没有结果时明确显示“暂无记录”。

## 信息层级

- 输入与结果摘要保持在前；
- 已提交输入和判断边界在风险页中折叠；
- CSV管理与风险筛查分开；
- 参数明细、规则、模型限制和缺口集中在科研依据页；
- 安全限制和缺失数据提示不会隐藏在详情页。

## 全局评估状态

每个页面顶部显示轻量“当前评估状态”：

- 首次进入且未提交风险情景时显示“暂无记录”；
- 风险页提交后显示“已提交计算”；
- 显示当前情景来源、数据完整性和结果来源；
- 不在每个页面重复完整风险摘要。

## CSV会话状态

- 上传成功后保存在当前浏览器会话；
- 页面之间切换不会丢失；
- 刷新页面、关闭浏览器或开启新会话后不保证保留；
- 上传不同文件时创建下一会话版本，并替换当前版本的显示结果；
- 相同文件内容不会重复创建版本；
- 单行解析失败不会阻止其他有效行计算；
- 可分别下载原始上传CSV与“原始字段＋计算结果”CSV；
- 可手动清除当前会话上传。

本版未引入React、Vue、数据库或登录系统。
