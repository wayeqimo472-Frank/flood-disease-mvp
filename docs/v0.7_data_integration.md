# v0.7 数据拼接

日期：2026-11-13

## 目标

在 v0.6 案例包和本地 SQLite 基础上，增加公开数据索引、ICASA 字段映射、田块几何导入和 SAR 洪水指标导入。主风险引擎不直接依赖 FTW、SAR 深度学习模型或 farmOS。

## 已接入

### ICASA 字段映射

- 来源：https://github.com/DSSAT/ICASA-Dictionary
- 代码与字典许可：BSD-3-Clause
- 本地映射：`data/icasa_field_mapping_v0.1.csv`
- 使用方式：只采用字段子集、代码和单位，不安装 DSSAT，不复制整套字典

映射区分 `exact`、`partial`、`derived` 和 `no_standard`。明水天数、渍水天数、排水延迟、V/R 生育期、病害严重度和诊断状态目前没有可直接等同的通用 ICASA 字段，继续保留为本项目扩展字段。

### 田块几何

- 来源候选：https://github.com/fieldsoftheworld/ftw-baselines
- 代码许可：MIT
- 输入：GeoJSON `FeatureCollection`
- 必需属性：`properties.field_id` 或 `properties.plot_id`
- 支持：`Polygon`、`MultiPolygon`

FTW 输出标记为 `remote_sensed` 和 `model_prediction`；人工测绘标记为 `observed` 和 `field_survey`。预测边界不写回田块实测边界。

### SAR 洪水指标

- 研究候选：https://github.com/cloudtostreet/Sen1Floods11
- 当前状态：只定义数据接口，未打包模型代码或检查点
- 必需字段：`field_id`、`event_id`、`event_date`、`flooded_area_pct`
- 可选字段：洪水起止、退水日、最大水深、场景 ID 和方法版本

所有导入值标记为 `remote_sensed`。最大水深字段是遥感或模型估算，不能冒充田块实测水深。

### 公开数据

`tools/import_public_data.py` 会把以下来源写入 `data/app.db`：

- 美国 CSCAP 9 张处理表；
- 公开证据 v0.2 的数据与派生结果；
- 远端公开案例目录、真实淹水 NDVI、涝渍基因型存活和病害进展参数；
- 项目公开数据登记、缺口矩阵和 50 项逐字段缺失清单。

相同文件按 SHA256 去重。源文件变化时替换该数据集的记录。

## 数据库

| 表 | 用途 |
|---|---|
| `external_datasets` | 数据集来源、许可、证据等级、哈希和行数 |
| `external_records` | 外部 CSV 的逐行 JSON 记录 |
| `plot_geometries` | 田块边界、来源和证据等级 |
| `plot_flood_metrics` | 地块洪水指标、来源和证据等级 |

## 未接入

- farmOS：核心为 GPL-2.0，当前只借鉴概念，未复制代码；
- ML4Floods：代码 LGPL-3.0，数据和模型含 CC BY-NC 限制，暂作候选；
- PlantVillage：许可未确认，且不能补同田块连续时序；
- DSSAT：依赖重，当前只需要 ICASA 字典；
- FTW 和 SAR 重推理环境：保持独立 worker，避免拖慢主应用。
